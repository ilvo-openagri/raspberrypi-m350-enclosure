# OpenAgri M350 Enclosure

This repository contains the `OpenAgri Case V2.f3z` CAD archive for the OpenAgri Raspberry Pi M350 enclosure.

## Opening the Design

Open the `.f3z` archive in Autodesk Fusion to view or continue editing the enclosure design. This repository currently provides the CAD archive; it does not include manufacturing instructions or exported fabrication files.
